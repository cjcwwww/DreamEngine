### 参数树

28 个常用效果、228 行参数记录导出成功。样例：

```
ADBE Bulge: 水平半径[OneD](0~8000), 垂直半径[OneD](0~8000),
            凸出中心[TwoD_Spatial], 凸出高度[OneD](-4~4), ...
ADBE Twirl: 角度[OneD], 旋转扭曲半径[OneD](0~100), 旋转扭曲中心[TwoD_Spatial]
```

**关键事实：中文界面下 `prop.name` 是中文**（"模糊度""数量""凸出高度"）。
之前按英文名写的配方大部分落空——CC Bender 渲出来"看不出效果"就是这个原因。

### 配方渲染

```
ITEM|ADBE Bulge|OK|1.54s
ITEM|ADBE Twirl|OK|1.27s
ITEM|ADBE Sharpen|OK|1.31s
ITEM|ADBE Radial Blur|OK|1.29s
ITEM|ADBE Mosaic|OK|1.22s
```

裁出单格放大 2 倍目视核对：

- **Bulge**：水平细线在中心鼓起，橙色块下边缘被推成弧形 —— 生效
- **Twirl**：画面整体被涡旋拉扯，文字变形 —— 明显生效
- **Mosaic**：画面分解成约 14×14 方块 —— 明显生效

## 3. 本轮暴露的问题

### 3.1 文本生成器会弹模态对话框（严重）

`ADBE Numbers2` 在 `addProperty` 时弹出「编号」参数对话框，脚本卡在等输入，
AE 表现为"未响应"。第一次排查时误判为崩溃。`ADBE Timecode` 同类。

处置：三处（候选筛选 / 隔离批次 / M2 探针）全部排除，并补测试断言。

### 3.2 预览卡片太小，细节效果看不出来

Bulge 在 2048 整网的缩略图里看起来"和原图一样"，裁剪放大 2 倍后才能看到细线鼓起。
卡片实际显示约 140px，256px 的格子细节被压缩掉了。

这属于产品层面的取舍，不是 bug。可选改进：卡片悬停放大、或卡片放大到 180–200px。

### 3.3 CC 系列参数名仍是未知

本轮只导出了 28 个 ADBE 效果。CC 系列（Cycore）参数可能是英文，
配方里的 `Amount` / `Size` 是否命中尚未验证。下次应把 `CC Bender`、`CC Burn Film`
等加入导出清单再核对。

### 3.4 渲染速度观察（未做严格对照）

素材改为会话内缓存后，单条渲染稳定在 1.2–1.6 秒；此前逐条测试时观察到 ~25 秒/条。
但这个对比不严谨——首次渲染包含 AE 插件预热成本。**不能据此宣称 15 倍提速**，
需要同会话、同批次的 A/B 才能定论。
