| 类型 | 谁能独立完成 | 说明 |

## 1. M0 · 探针（前置闸门）

> 目标：用实测数据替掉设计里所有"需实测"的空格。**M0 不做完，M2 的内置包规模、帧数、网格尺寸都只能拍脑袋。**

- **T0.1 效果枚举探针** `【需用户实跑】`
  - 输入：目标机器（主力 AE 版本 + CC2022/2023 各一台或切换版本）
  - 产出：`probe-effects.json`（`displayName/category/matchName/version` 全量）+ 条数统计、`category` 分布、第三方效果占比
  - 验收：确认第三方插件效果**全部**出现在 `app.effects` 中；`category` 在各插件上的真实形态（是否等于插件名）有实例样本

- **T0.2 渲染耗时与尺寸探针** `【需用户实跑】`
  - 输入：1 个纯色素材 + 随机 8 个效果，两种模式各跑：逐效果单帧 vs 8×8 整网单帧
  - 产出：`probe-render.json`：每项 `elapsedSeconds`、输出文件字节数（`RenderQueueItem.elapsedSeconds` 可读）、`timeSpanStart/timeSpanDuration` 生效证明
  - 验收：得出**每格每帧平均秒数与平均 KB** 的实测基数（这两个数直接决定 L1 能塞多少效果、几帧动画）

- **T0.3 CEF 纹理上限与轮播解码探针** `【需用户实跑】`
  - 输入：CEP 最小壳 + 2048/4096 两档整网图 + 12 帧轮播
  - 产出：`probe-cef.md`：可正常显示的尺寸上限、轮播是否掉帧、GIF/WebP/帧序列轮播三者的可用性结论
  - 验收：定下 `tileSize × gridN × frameCount` 的安全参数组合

- **T0.4 applyPreset 行为探针** `【需用户实跑】`
  - 输入：3 个真实预设（一个纯效果预设 / 一个文本动画预设 / 一个变换关键帧预设）
  - 产出：`probe-preset.json`：有选中层、无选中层、错图层类型三种情况各自的行为（是否新建纯色层 / 是否报错 / 是否静默无效果）
  - 验收：把"必须先隔离选区 + 结果校验 + 四场景重试"的每一步都拿到实证，失败形态有明确枚举

- **T0.5 下拉选项版本差异探针** `【需用户实跑】`
  - 输入：同一效果（如 CC Colorama / Curve）在 CC2022 与 2026 上分别读取
  - 产出：`probe-dropdown.json`：`propertyParameters`/`valueText` 是否可用、不可用时能拿到什么（索引）
  - 验收：确认降级显示方案，并给出**需要自带映射表来补的内置效果清单范围**

- **T0.6 文件对话框与拖拽探针** `【需用户实跑】`
  - 输入：CEP 面板 + `File.openDialog(multiSelection=true)` / `Folder.selectDialog` / HTML5 拖拽
  - 产出：`probe-import.md`：多选是否可用、拖拽能否取到真实文件路径、`.ffx` 过滤是否生效、递归扫目录取 `.ffx` 的耗时
  - 验收：明确拖拽入口保留或降级为两入口

- **T0.7 aerender 离线生成探针** `【需用户实跑】`
  - 输入：命令行调用 `aerender -r xxx.jsx`，复用同一套 previewgen 雏形
  - 产出：`probe-aerender.md`：能否加载第三方插件、能否读用户目录配置、多进程并发的实际限制与许可条款核对结论
  - 验收：决定离线生成器走 aerender 子进程，还是退回 AE 内分批队列

- **T0.8 内置表覆盖率对撞** `【可离线完成，依赖 T0.1】`
  - 输入：T0.1 的实测 matchName 清单 + M0.5 的 `names.json`
  - 产出：覆盖率报告：命中 / 未命中 / 冲突三类计数与占比
  - 验收：量化 L-C 兜底比例，作为 M0.5 是否达标的判据

- **T0.9 M0 实测报告 → 参数定版** `【可离线完成】`
  - 产出：把实测值回填设计文档：网格尺寸、每网效果数、动画帧数、L1 效果总数、批渲节奏、拖拽入口取舍、并发进程数
  - 验收：设计文档里不再残留任何"需实测"占位

**M0 出口判据：T0.1–T0.7 全部有结论，T0.9 回填完成。**
