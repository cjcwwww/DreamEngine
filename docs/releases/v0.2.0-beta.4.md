# DreamEngine Beta v0.2.0-beta.4

第四个公开 Beta，重点修复卸载不完整和重装残留旧数据的问题。

## 修复

- 从 Windows 设置或开始菜单卸载时，同时删除 After Effects 的 DreamEngine CEP 面板脚本
- 完全清理预设库、背景、素材缓存、收藏数据和 Hub 路径标记
- 清理 CEP 面板的 `localStorage`，不再残留收藏、分类、卡片尺寸和历史设置
- 清理 `Documents/DreamEngineProbe` 中的渲染状态、日志和探针数据
- 清理 Hub 的 Electron 用户数据、更新缓存、本地缓存和临时渲染目录
- 卸载时恢复安装前的 CEP `PlayerDebugMode`，不再残留 DreamEngine 写入的调试开关
- 开发机的 CEP Junction 只删除链接本身，不会误删它指向的仓库
- 升级仍会保留用户预设、背景、分类、收藏和已生成预览；完全清理只发生在真正卸载时
- 预设和插件效果渲染会识别 After Effects 原生报错弹窗，自动跳过出错条目并继续
- 自定义预览背景导致导出报错时，自动改用标准背景继续当前任务
- 修复安装包内置 AEP 带旧 PNG 素材引用和开发机绝对输出路径的问题
- 模板渲染前会按当前机器重写临时输出目录，不再使用打包机器的账户路径

## 安装

1. 保存工程并关闭 After Effects。
2. 运行 `DreamEngine-Hub-Setup-0.2.0.exe`。
3. 启动 AE，打开 `窗口 > 扩展 > DreamEngine`。

安装包未签名，SmartScreen 可能提示未知发布者。

## 卸载

在 Windows 设置 > 应用或开始菜单中卸载 DreamEngine Hub。卸载会删除全部 DreamEngine 用户数据；如需保留预设，请先备份 `文档/DreamEngine/`。

# DreamEngine Beta v0.2.0-beta.4

The fourth public beta fixes incomplete uninstalls and stale data left behind after reinstalling.

## Fixed

- Uninstalling from Windows Settings or the Start menu now removes the DreamEngine CEP panel scripts from After Effects
- Removes the preset library, backgrounds, media cache, favorites data, and Hub path marker
- Removes the CEP panel's `localStorage`, including favorites, categories, card sizes, and saved UI state
- Removes render state, logs, and probe data from `Documents/DreamEngineProbe`
- Removes Hub Electron user data, update cache, local cache, and temporary render files
- Restores the previous CEP `PlayerDebugMode` state instead of leaving DreamEngine's debug setting behind
- On development machines, the CEP Junction is unlinked without deleting the repository it points to
- Upgrades still preserve user presets, backgrounds, categories, favorites, and generated previews; full cleanup runs only on a real uninstall
- Preset and plugin-effect rendering now detect native After Effects dialogs, skip the failing item, and continue
- If a custom preview background causes an export error, rendering automatically falls back to the standard background
- The bundled AEP no longer references an old PNG asset or a developer-machine output path
- Template rendering rewrites its temporary output path for the current machine before queuing

## Installation

1. Save your project and close After Effects.
2. Run `DreamEngine-Hub-Setup-0.2.0.exe`.
3. Start AE and open `Window > Extensions > DreamEngine`.

The installer is unsigned, so SmartScreen may show an unknown-publisher warning.

## Uninstall

Uninstall DreamEngine Hub from Windows Settings > Apps or the Start menu. Uninstalling removes all DreamEngine user data; back up `Documents/DreamEngine/` first if you need to keep your presets.
