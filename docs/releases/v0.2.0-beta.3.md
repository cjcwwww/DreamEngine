# DreamEngine Beta v0.2.0-beta.3

第三个公开 Beta，补齐多版本 AE 兼容、效果预览背景和 Hub 插件效果预览生成。

## 新增

- 效果清单记录当前 AE 版本，并按 AE 主版本选择预览
- 缺少当前版本预览时静默回退到其他版本的同名预览
- 默认显示当前 AE 的全部已安装效果，当前版本独有效果也能加入生成队列
- AE 设置页支持上传效果预览背景，并可恢复默认素材
- Hub 新增「插件效果」页，使用当前 AE 的插件清单逐条生成第三方效果预览
- 插件效果生成支持批次大小、最大轮数、进度显示、停止与断点继续
- 同一专用 AE 实例会连续处理多个批次，批次间自动清理，只有崩溃或超时才重启实例
- 预设页右上角增加打开 DreamEngine Hub 的按钮

## 修复

- 效果渲染结束后自动清理 AE 工程里的临时合成、临时素材和导入的帧序列
- 插件预览不再被误加入内置效果的重渲队列
- 修复 Hub 插件效果生成器在 Windows PowerShell 5 下因 UTF-8 无 BOM 而无法启动的问题
- 修复 AE 2023 未执行插件效果离线 JSX 的问题，改为通过小加载器读取并执行渲染脚本
- 修复插件效果渲染完成后 AE 实例不自动退出的问题，出现 `RESULT` 后立即回收专用实例
- 背景或素材改变后只让对应效果的旧预览失效
- 重渲时保留旧索引指纹，避免未完成重渲的条目被误标成新预览
- 素材页不再显示已删除的文件
- 继续清理宿主工程里历史遗留的 DreamEngine 中间对象

## 安装

1. 保存工程并关闭 After Effects。
2. 运行 `DreamEngine-Hub-Setup-0.2.0.exe`。
3. 启动 AE，打开 `窗口 > 扩展 > DreamEngine`。

安装包未签名，SmartScreen 可能提示未知发布者。

## 已知限制

- 第三方插件效果依赖本机插件环境。
- 插件效果必须通过 Hub 的独立 AE 实例生成，不能在宿主 AE 中混渲。
- 自定义效果背景只用于普通画面类效果；文字、形状、遮罩和两层输入类效果保留专用图层。

# DreamEngine Beta v0.2.0-beta.3

The third public beta, adding multi-version AE support, effect-preview backgrounds, and plugin-effect generation in Hub.

## Added

- Effect catalogs now record the current AE version and select previews by AE major version
- Missing current-version previews fall back silently to same-name previews from other versions
- The panel now shows all installed effects for the current AE by default, including version-specific effects that can be queued for rendering
- AE settings now support uploading a custom effect-preview background and restoring the default asset
- Hub has a new Plugin Effects page that reads the current AE plugin catalog and renders previews one by one
- Plugin-effect rendering supports batch size, maximum rounds, progress, cancellation, and resume
- A dedicated AE instance now continues through multiple batches and is restarted only after a crash or timeout
- A Hub launch button is available in the preset page header

## Fixed

- Temporary comps, assets, and imported frame sequences are removed from the AE project after rendering
- Plugin previews are no longer accidentally queued as built-in effect rerenders
- Fixed the Hub plugin-effect generator failing to start in Windows PowerShell 5 because of UTF-8 files without a BOM
- Fixed AE 2023 not executing the offline plugin-effect JSX by running it through a small loader script
- Fixed the dedicated AE instance remaining open after rendering; it is now terminated immediately after `RESULT`
- Changing a background or source asset only invalidates the affected previews
- Existing manifest keys are preserved while a rerender is in progress
- Deleted material files no longer appear as missing entries
- Historical DreamEngine intermediate objects are cleaned from the host project

## Installation

1. Save your project and close After Effects.
2. Run `DreamEngine-Hub-Setup-0.2.0.exe`.
3. Start AE and open `Window > Extensions > DreamEngine`.

The installer is unsigned, so SmartScreen may show an unknown-publisher warning.

## Known limitations

- Third-party plugin previews depend on the local plugin installation.
- Plugin effects must be rendered by Hub in isolated AE instances; they cannot be mixed into the host AE session.
- Custom effect backgrounds apply to general footage-style effects. Text, shape, matte, and two-layer effects keep their dedicated source layers.
