# DreamEngine Beta v0.2.0-beta.6

第六个公开 Beta，重点加入效果库与选择性渲染，完善素材页的目录浏览，并修复多版本 After Effects 的检测问题。

## 新增

- Hub 新增「效果库」页：AE 内置效果与扫描到的第三方插件效果合并列出，按来源分组（AE 内置、BCC、Sapphire、Red Giant、RE:Vision、Video Copilot、其它插件），支持搜索、来源筛选、只看收藏与悬停播放
- 尚未生成预览的效果显示为「待渲染」占位；列表会跳过已失效的预览，并把被误判为插件的效果归回 AE 内置分组，分组折叠状态与分类栏宽度都会被记住
- 效果卡片支持勾选、收藏、单独渲染、清除预览与右键菜单；清除预览会一并清理索引、帧文件与黑名单记录，让效果回到待渲染状态，收藏单独保存，升级不会丢失
- 「同步 AE 分类」只重新扫描插件效果目录、不渲染，扫描结果带回每个效果的 AE 分类、排除原因与预览状态
- 「渲染 → 插件效果」页可先扫描插件目录，再按插件或名称勾选要渲染的效果，只渲染所选条目；「强制重渲」可以重新处理已生成或已跳过的效果
- 预设页支持勾选多条预设只渲染所选，也能一键选中当前筛选下所有未渲染的预设
- 自动索引当前 AE 的安装预设与用户预设目录（只建索引、不复制文件），可按来源筛选并按 AE 来源文件夹分组；外部预设可渲染，但不能重命名或删除，右键可打开所在文件夹
- 渲染任务会校验所选条目、清理上一轮残留的任务标记，并在目录扫描结束后把最新清单推回界面
- 素材页可以双击进入子文件夹，顶部面包屑的每一段都能点击回退，路径过长时省略中间段但保留首末段；分类计数与搜索都限定在当前目录，空文件夹不显示
- 刷新与更换素材目录改为右上角两个图标；刷新后仍留在当前目录，目录不存在时回退到最近存在的上级，左栏只保留分类列表，相关图标提示补齐中英文文案
- 插件预览引擎会给出稳定的排除原因（伪效果、已废弃、缺少分类、预览不佳），并支持按「强制」忽略已渲染与黑名单记录、按「跳过」避免同轮重试来规划预览批次
- 新增 Hub 数据层的 Node 断言（目录解析、预设索引、效果合并、渲染参数、批次规划与排除原因），渲染夹具改为自包含、不依赖仓库路径，可通过 `npm test` 运行
- 补齐中英文说明文档：效果库、选择性渲染、AE 预设索引、探针文件与命令参数约定，以及上一版多点曲线编辑器的用法

## 修复

- 按每个 After Effects 版本各自的 InstallPath 定位已安装版本，后装版本不再覆盖先前记录，自定义安装盘也能识别；App Paths 降为补充，并保留各盘 Program Files / Adobe 的兜底查找
- 修复 App Paths 中带引号且带图标索引（例如 `"C:\...\AfterFX.exe",0`）的路径解析，避免注册表不可用时漏检 AE
- 文字与动画类 AE 预设改用文字舞台预览：先应用到合成里已有的文字层，没有文字层时自动改用内置「文字」素材，不再被误报为「应用失败」或只存下一张静帧
- 延长内置文字素材的时长，避免嵌套合成在一秒后消失；清理残留的原始帧文件，下一轮渲染不再弹出「文件已存在，是否覆盖」
- 素材卡片选中框改为覆盖整张卡片（含名称）的白框，不再被铺满卡片的缩略图遮住，也不会挡住收藏星标

## 安装

1. 保存工程并关闭 After Effects。
2. 运行 `DreamEngine-Hub-Setup-0.2.0.exe`。
3. 启动 AE，打开 `窗口 > 扩展 > DreamEngine`。

安装与升级只替换程序文件，不覆盖用户已生成的预览与预设库。

安装包大小：144,742,902 字节（138.03 MB）；SHA256：`950C15620D2A95E530C088C1711B01504348729521A14EAD3FA734FA9969B1E8`。

安装包未签名，SmartScreen 可能提示未知发布者。

# DreamEngine Beta v0.2.0-beta.6

The sixth public beta adds the effects library and selective rendering, improves folder browsing on the materials page, and fixes detection of multiple After Effects versions.

## Added

- Added an "Effects Library" page in the Hub: built-in After Effects effects and scanned third-party effects are listed together, grouped by source (AE Built-in, BCC, Sapphire, Red Giant, RE:Vision, Video Copilot, Other), with search, source filter, favorites-only and hover playback
- Effects without a preview show as pending placeholders; dead previews are dropped and effects misclassified as plug-ins are grouped back under AE Built-in; group collapse state and sidebar width are remembered
- Effect cards support selection, favorites, single render, clear preview and a context menu; clearing a preview removes its index, frames and blacklist record so the effect returns to pending, while favorites are stored separately and survive upgrades
- "Sync AE categories" re-runs a catalog-only scan without rendering; the scan reports each effect's AE category, exclusion reason and preview state
- The Render > Plugin Effects page can scan the plugin catalog first, then pick effects by plug-in or name and render only the checked matchNames; "force rerender" re-processes already rendered or previously skipped effects
- The preset page supports multi-select renders and one-click selection of every unrendered preset in the current filter
- The selected AE's installed Presets and User Presets folders are indexed automatically (index only, no copying), with a source filter and grouping by AE source folder; external presets can be rendered but not renamed or deleted, and the context menu opens their containing folder
- Render jobs validate the selection, clear stale job markers from the previous run and push the refreshed catalog to the UI when a catalog scan finishes
- The materials page can enter subfolders by double-clicking; every breadcrumb segment is clickable, long paths omit the middle while keeping the first and last segments, and category counts and search are limited to the current folder; empty folders are hidden
- Refresh and change-folder are now two icons in the top-right; refresh keeps the current folder, falling back to the nearest existing parent if it no longer exists, the left sidebar holds only the category list, and the new icon labels are translated
- The plugin preview engine now reports stable exclusion reasons (pseudo, obsolete, no category, poor preview) and plans preview batches with force and skip options, so already rendered or blacklisted entries can be bypassed and names are not retried in the same round
- Added Node assertions for the new Hub data layers (catalog parsing, preset sources, effect merging, spawn arguments, batch planning and exclusion reasons); render job fixtures are now self-contained and the suite runs with `npm test`
- Documentation updated in Chinese and English: the effects library, selective renders, the AE preset index, the probe-file and command-switch contract, and the multi-point curve editor from the previous beta

## Fixed

- Installed After Effects versions are now located through each version's own InstallPath, so a later install no longer overwrites earlier records and custom install drives are detected; App Paths is only a fallback, with per-drive Program Files / Adobe scanning as a last resort
- Fixed parsing of App Paths values that contain both quotes and an icon index (for example `"C:\...\AfterFX.exe",0`), which previously caused an AE install to be missed when the registry path was unavailable
- Text and animation AE presets are now previewed on a text stage: applied to an existing text layer first, then to the bundled "text" background asset, instead of being reported as "preset did not apply" or captured as a still frame
- The bundled text asset now lasts long enough for nested compositions, and leftover raw frame files are removed so the next render does not ask to overwrite existing files
- The materials card selection outline is now an overlay covering the whole card (including its name), so it is no longer hidden by full-bleed thumbnails and does not block the favorite star

## Installation

1. Save your project and close After Effects.
2. Run `DreamEngine-Hub-Setup-0.2.0.exe`.
3. Start AE and open `Window > Extensions > DreamEngine`.

Installing or upgrading replaces the program files only; generated previews and the preset library are left untouched.

Installer size: 144,742,902 bytes (138.03 MB); SHA256: `950C15620D2A95E530C088C1711B01504348729521A14EAD3FA734FA9969B1E8`.

The installer is unsigned, so SmartScreen may show an unknown-publisher warning.
