# DreamEngine Beta v0.2.0-beta.5

第五个公开 Beta，重点加入多点曲线编辑与曲线工具栏，并修复 AE 侧关键帧写入的边界问题。

## 新增

- 曲线页加入两点/多点编辑模式、读取当前曲线、反向、换键、左右冻结、网格磁吸和本地撤销/重做
- 支持在曲线上双击插入节点、拖动节点与把手、删除中间节点
- 内置多点曲线预设，并支持保存和删除自定义多点曲线预设
- 面板顶栏使用一个搜索框统一筛选效果、预设和素材
- 曲线页采用可拖动分区布局，宽屏和窄面板下都能保持操作区可用

## 修复

- 非首段多关键帧应用不再写错选区外的关键帧
- 曲线反向改为逐段水平镜像，回弹和过冲曲线不会再被错误旋转
- Ease 写入部分失败时不再错误显示为成功
- 空间属性换键时同步交换空间切线，左右冻结时清零切线
- 修复 ExtendScript 保留字导致的 AE 脚本执行失败
- 补齐曲线错误提示，并修复窄面板分隔条比例计算
- 网格磁吸统一为 0.1 网格
- 预览渲染时间范围会按合成实际显示区间安全收敛

## 安装

1. 保存工程并关闭 After Effects。
2. 运行 `DreamEngine-Hub-Setup-0.2.0.exe`。
3. 启动 AE，打开 `窗口 > 扩展 > DreamEngine`。

安装包未签名，SmartScreen 可能提示未知发布者。

# DreamEngine Beta v0.2.0-beta.5

The fifth public beta adds multi-point curve editing and fixes boundary cases in After Effects keyframe writes.

## Added

- Two-point and multi-point curve modes with read, reverse, key swap, left/right freeze, grid snapping, and local undo/redo
- Insert curve nodes by double-clicking, drag nodes and handles, and delete middle nodes
- Built-in multi-point curve presets plus custom multi-point preset save/delete
- One top-bar search control for effects, presets, and materials
- Resizable curve workspace that remains usable in both wide and narrow panels

## Fixed

- Multi-keyframe application no longer writes ease data outside the selected range
- Curve reverse now mirrors each segment horizontally instead of rotating overshoot curves
- Partial ease-write failures are no longer reported as success
- Spatial tangents are swapped with keyframes and cleared when freezing
- Fixed an ExtendScript reserved-word error that prevented the AE script from running
- Improved curve error reporting and corrected narrow-layout ratio calculation
- Unified snapping to a 0.1 grid
- Preview render ranges are clamped to the composition's actual visible range

## Installation

1. Save your project and close After Effects.
2. Run `DreamEngine-Hub-Setup-0.2.0.exe`.
3. Start AE and open `Window > Extensions > DreamEngine`.

The installer is unsigned, so SmartScreen may show an unknown-publisher warning.
