# probe-results/AE2021/

本目录存放 **AE 2021（18.4.1）** 上实测回传的探针原始数据，**必须入库**。

理由：M0 的实测报告与 T0.9 参数定版结论都建立在这些原始数据上。
把原始数据纳入版本控制，是为了让「结论可回滚、可复核」——
日后若怀疑某个渲染参数定错，能直接翻回当时的耗时/体积实测记录，而不是只看到结论。
