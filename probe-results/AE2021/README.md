# probe-results/AE2021/

本目录存放 **AE 2021（18.4.1）** 上实测回传的探针原始数据，**必须入库**。

理由：M0 的实测报告与 T0.9 参数定版结论都建立在这些原始数据上。
把原始数据纳入版本控制，是为了让「结论可回滚、可复核」——
日后若怀疑某个渲染参数定错，能直接翻回当时的耗时/体积实测记录，而不是只看到结论。

## 期望文件

```
T0_1_效果枚举.txt
T0_2_渲染耗时.txt
T0_4_预设应用_*.txt        （3 份，对应三个测试预设）
T0_5_参数读取.txt
T0_6_导入探针.txt
T0_3_CEF探针.txt           （CEP 面板写入）
T0_3_env.txt               （CEP 面板写入）
T0_6b_拖拽.txt             （CEP 面板写入）
探针日志.txt               （汇总行）
T0_7_aerender输出.txt      （三条命令输出全文）
```

数据来源目录：`C:\Users\31371\Documents\AEViewerProbe\`

## 不入库的内容

`AEViewerProbe/` 原始输出目录本身、以及 sprite sheet PNG 等渲染产物
均已在仓库根 `.gitignore` 中排除（体积大、属二进制产物）。
本目录只收文本类实测记录。

## 版本说明

本机只有 AE 2021 一个版本，所有实测结论按「CC2022+ 的下界」解读。
若日后装了新版本，另建 `probe-results/CC2022/` 等平行目录，**不要覆盖本目录**。
