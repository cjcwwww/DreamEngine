# DreamEngine M0 阶段报告（AE 2021）

日期：2026-11-03  
环境：After Effects 18.4.1x4，Windows

## 已完成

### T0.1 效果枚举

- `app.effects` 总数：1371
- 分类为空：100
- obsolete / 过时：215
- `Pseudo/`：3
- 已保存完整 `matchName / displayName / category`：`T0_1_full.tsv`

### T0.2 渲染耗时

- 目标规模：8×8 整网，2048×2048，64 格，6 帧
- 单效果模式：16/16 成功，总计约 16.55 秒，平均约 1.03 秒/单帧
- 整网模式：6 帧约 2.24 秒，平均约 0.006 秒/格/帧
- 整网 PNG：6 张，共约 119 KB，平均约 20 KB/张
- 输出模板：`DreamEngine PNG Sequence`
- 限制：单帧平均 KB 只有约 1 KB，因为测试素材是纯色层；不能直接代表真实视频素材的 L1 体积

### T0.3 CEF

- WebGL 纹理上限：16384
- 2D Canvas：8192×8192 仍可正常读写
- WebP / GIF / PNG：支持
- 2048×2048 PNG 解码：约 2-7 ms
- 6 帧轮播：0 次超过 25 ms

### T0.4 applyPreset

- 不匹配的预设可能无报错但无效果
- 文本预设作用在纯色层：静默无效
- 文本层：3 个含关键帧的属性
- 无选中层：会新增图层
- M3 必须做结果校验、场景重试和自动图层清理

### T0.5 参数读取

- 40 个效果成功添加
- `propertyParameters` 可用：0
- `valueText` 可用：0
- min/max 可读：484 项
- units 可读：100 项
- 结论只适用于 AE 2021，不能证明 CC2022/2023/2026

### T0.6 / T0.6b 导入

- 多选返回数组，实测 30 个 `.ffx`
- 递归扫描 622 个 `.ffx` 用时 742 ms
- CEF File 对象可取真实绝对路径

### T0.7 aerender

- 不支持 `-r`
- `Format` 不能通过 outputSettings 改写
- 含 `S_Glow` 的工程可由 aerender 独立渲染成功
- 许可并发未核实，默认单进程

### T0.8 名字对撞

- 第一方表：266 条，校验 0 问题
- BCC：329 条，英文名命中 300，其中同名多命中 28，未命中 1
- 当前中文可显示 BCC：0
- 本轮范围：第一方 + BCC；其他插件走 L-C

## 结论

M0 出口条件已满足：T0.1-T0.8 均有结论，T0.9 参数已写入 `config/render_params.jsxinc`。

版本边界仍然明确：当前实测只覆盖 AE 2021/CEP 11.1；CC2022+ 的兼容性需要在后续目标版本补跑，不能把 AE 2021 的结果外推成完整兼容证明。
