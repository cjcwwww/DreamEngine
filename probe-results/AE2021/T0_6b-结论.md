# T0.6b CEP 文件路径结论（AE 2021 / CEP 11.1）

- 使用 CDP 将真实 `.ffx` 文件设置进 CEF 文件输入，再装入 `DataTransfer` 触发 drop。
- 测试文件：`Image - Special Effects/夜视.ffx`
- 大小：937,595 字节
- `dataTransfer.files[0].path` 返回完整绝对路径。

结论：CEF 暴露了文件对象的路径扩展属性，M3 保留拖拽入口。

边界：本测试验证的是 CEP 对真实文件的 `File.path` 行为，并通过真实 `DataTransfer` 走完项目 drop 处理器；没有模拟资源管理器中的鼠标拖拽手势。若后续在真实拖动中发现异常，再降级为“选文件/选文件夹”仍不影响功能。
