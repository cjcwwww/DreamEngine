# T0.4 applyPreset 结论（AE 2021 / 18.4.1x4）

测试预设：

- 纯效果：`Image - Special Effects/夜视.ffx`
- 文本动画：`Text/3D Text/3D 在位置 Z 飞入.ffx`
- 变换关键帧：`Transform/分离 XYZ 位置.ffx`

## 关键结论

1. `applyPreset` 对不匹配的图层类型通常**不报错**，只表现为无效果或无动画。
2. 文本预设作用在纯色层上时，效果数和关键帧属性数都没有增加，属于静默无效。
3. 文本预设作用在文本层上时，记录了 3 个含关键帧的属性。
4. 无选中层时调用会新增图层；三组测试中图层数均从 1 变为 3，后续文本层和调整层又继续增加图层。
5. 因此 M3 必须执行：
   - 调用前清空选区，只选中目标层；
   - 调用后比较效果数、关键帧属性和图层数；
   - 按 `solid -> text -> footage -> adjustment` 重试；
   - 删除自动创建的图层时使用 `remove()`，不依赖撤销。
